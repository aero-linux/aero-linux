📐 KERNEL & USERSPACE SPECIFICATION

Deep Systems Architecture

Explore the four zero-bloat engineering layers powering Aero Linux's sub-350MB idle RAM and microsecond execution speed.

KERNEL SUBSYSTEM

Dynamic In-Memory zRAM (ZSTD)

Aero completely eliminates traditional disk swap thrashing. Memory pages are compressed dynamically inside RAM using multi-threaded ZSTD compression (~2.8:1 ratio), providing ~25GB+ usable workspace on a 16GB physical laptop.

⚡
Sub-Millisecond Paging: Memory compression operations run at ~10GB/s in DDR4/DDR5 RAM, eliminating 100x latency stalls from NVMe SSD swapping.
🛡️
SSD Endurance Preservation: Zero disk write cycles dedicated to swap files protects NAND flash cells from premature wear.
⚙️
Kernel Parameters: vm.swappiness=180, vm.watermark_boost_factor=0, vm.page-cluster=0.
/etc/sysctl.d/99-aero-performance.conf ACTIVE 
# In-Memory zRAM Allocation (100% RAM disk)
vm.swappiness = 180
vm.watermark_boost_factor = 0
vm.watermark_scale_factor = 125
vm.page-cluster = 0
vm.dirty_ratio = 10
vm.dirty_background_ratio = 5

# Real-time Hardware sysfs Verification:
$ cat /sys/block/zram0/comp_algorithm
[zstd] lz4 lzo
$ aero memory --optimize
✔ Compacted 420MB zRAM pages. Headroom expanded.

Adaptive Power & 80% Battery Cap

Direct hardware-level ACPI integration manages battery longevity and dynamic processor energy-performance preferences (EPP) across AC and battery power states.

🔋
80% Lithium Charge Cap: Enforces hardware charge threshold limits via ACPI, preventing battery cell oxidation during long desk sessions.
⚡
AMD P-State & Intel Speed Shift: Autonomous CPU frequency scaling (powersave on battery, boost on AC).
❄️
Acoustic Fan Curves: 0 RPM silent operation during low thermal loads with 1-click turbo cooling curves.

NETWORKING & SECURITY PROTOCOLS

Google BBR & Encrypted DNS-over-TLS

Optimized Linux TCP stack delivers maximum throughput and minimal bufferbloat on developer gigabit connections, paired with zero-trust local security rules.

🚀
Google BBR Congestion Control: Replaces legacy CUBIC with Bottleneck Bandwidth and RTT (BBR) for lower packet latency.
🔒
DNS-over-TLS (DoT): Encrypted upstream resolution via Cloudflare (1.1.1.1) and Quad9 preventing ISP DNS sniffing.
🛡️
Stateful UFW Firewall: Default deny incoming rules with 1-click port exposure (aero port kill 3000).
/etc/sysctl.d/99-bbr.conf ACTIVE 
# High-Throughput TCP BBR Stack
net.core.default_qdisc = fq
net.ipv4.tcp_congestion_control = bbr
net.ipv4.tcp_fastopen = 3
